# Issue tracker

Gainly's upstream proposals and implementation tasks use [GitHub Issues](https://github.com/enzosinger/gainly/issues). Check existing issues and pull requests before creating another. The planning record for the October 2026 reliability effort is in `.scratch/workout-reliability/`.

Contributors without upstream write permission may open issues and fork-based draft pull requests. They must not claim labels, assignments, or native dependency links were applied when the repository does not permit them. Use explicit `Status` and `Blocked by` text in that case. Do not change repository permissions to run this workflow.

## Wayfinding operations

Keep the map, research, spec, and one file per proposed task together in the effort directory. The map links resolved research decisions; each task names its real blockers. Link published GitHub issues from the local task records. Only implement tasks whose blockers are resolved and whose scope is authorized.

PRs as a request surface: off.
